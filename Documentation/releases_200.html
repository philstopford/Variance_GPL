New to 2.6.1 (May 8 2017)

  • Number of threads can now be set using '--threads x'.

New to 2.6 (Mar 26 2017)

  • Viewports support 'zoom extents'.
  • DOE viewport offers entry to go to bottom-left corner of grid.
  • Optimized viewport resets.
  • Convergence reporting for results.
  • Chord handler refined to address some edge case failures.
  • Enable contouring of extracted DOE geometry.
  • geoCore and geoLib enhancements.
  • Performance work:
    • Single-threaded 2x performance gain from sampled updates of the GUI (100 cases per update).
    • Enormous performance gains in multi-threaded (4-10x speedup) due to garbage collection change (server mode).
    • Smaller gains (1-5%) following some code optimizations.
  • Flip and rotate enhancements for polygon sheets, to flip and rotate around centre point.
  • Edge midpoint slide based on sigmoid function for previous/next edge length ratio.
  • ClipperLib upgraded to current version, with patches to address intersection point issues.
  • Headless updates, including interactive mode.
  • License system enhancements.

New to 2.5 (Dec 12 2016)

  • Shape engine enhancements.
  • Simplified implant calculation inputs.
  • Switched from angular resolution to segment count for corner definition UI input.
  • Context menus in viewports.
    • Toggle antialiasing, point display and filled polygons.
    • Freeze/thaw viewport mouse interaction.
    • Apply the camera position in one viewport to all others
    • Bookmark location in a viewport for later use
    • Rapidly zoom in/out by large amounts (5, 10, 50, 100x)
    • Retrieve the current viewport zoom level into the UI
  • Ability to freeze/thaw individual viewports through a hotkey (f).
  • Resolved issue that was clamping subshape inputs to integers
  • Ability to independently correlate tip and side CDU variations
  • 'Debug' mode (implementation depending on the calculation engine)
    • Used by overlap engine to show rays being cast, to aid set-up.
  • LER enhancements.
    • Much better algorithm to apply LER to the geometry.
    • Multiple noise sources for noise : Perlin, Simplex
    • Configurable frequency.
    • In-layer preview.
    • Internal changes to overlap handling to utilize averaged normal for raycast.

New to 2.4 (Oct 23 2016)

  • Advanced implant shadowing calculation.
    • Uses shape engine to contour resist, and tangent extraction to derive shadowing.
    • Monte Carlo engine available for full variation evaluation, as well as fast preview using nominal resist contour.

New to 2.3 (Sep 06 2016)

  • UI enhancements
    • Viewport can be navigated at any time now.
    • Feedback during long-running preview situations, to avoid impression tool has hung.
  • Allow geoCore to feed the internal shape engine.
    • Orthogonal geometry only, processed polygon-wise.
    • Compatible with multiple, arbitrary polygon data.
    • Works with DOE layouts.
    • Overlapping contours are merged.
  • Email password is now stored encrypted.
  • Performance improvement for zooming with the gadget in layer previews.
  • Option to fill polygons in viewports.
  • Intensive bug hunt and fix cycle following significant code disruption in the 2.x cycle so far.

New to 2.2 (Aug 01 2016)

  • Background polygon opacity in layer viewports.
  • General UI performance enhancements.
  • Eto.Forms GUI.
    • Full port of GUI to Eto.Forms. Common code across Windows/Mac/Linux now.
      • No impact on performance
      • Windows GUI no longer supports a headless mode (other GUI implementations never offered this). The headless binary remains available.
      • Preferences from older versions will not be migrated. Preferences are now stored in XML under the user account. Email password is stored plaintext in the file at this time.
  • Bug fixes:
    • Fixed issue with geoCore layers from changes in 2.1.

New to 2.1 (Jul 08 2016)

  • Enabling more layers (8 instead of 4). This is a major change that brings a lot of new code - it will take time to stabilize.
  • 'Show drawn' support for geoCore geometry.
  • Optimizations for the preview generation system, building on infrastructure enhancements.
  • Bug fixes:
    • Stability enhancement to the background layer system.

New to 2.0 (Jun 30 2016)

2.0 brought major changes to many areas of the application.

  • Average overlay implementation (against an arbitrary number of reference layers).
  • CSV generation now optional.
  • Interactive improvement: now able to set overlay references
  • Shape engine enhancements:
    • Performance optimizations in overlay calculation and application.
    • Now handles overlapping geometry within the same layer - previously, this was not a supported situation.
      • Behavior is configurable. Compatibility with all calculation modes is, however, not guaranteed. Chord identification is problematic with swiss-hole geometry.
  • Cryptographic RNG source now available. ~10% increase in runtime, but likely to be more evenly distributed than other sources.
  • Replacement of System.Drawing components (Point, PointF, Rectangle, RectangleF, Matrix) in common libraries due to Mono framework problems
  • R&D on Eto.Forms UIs that might enable cross-platform GUI
    • OpenGL viewports not viable yet on Mac/Linux
  • GeoCore for external geometry
    • Generalized system for external geometry parsing/utilization
    • Enabled improved GDS handling
    • Oasis support
  • Layout file-related tweaks.
    • Moved DOE registration controls to layer UI
    • 'Apply to all' for DOE configuration
    • DOE controls UI reworked
  • S-shape support.
  • Improved robustness in interactive and GUI.
    • Improved UI lockout methodology for invalid value settings based on shape type.
    • Simpler subshape handling in the preview displays
  • Bug fixes:
    • Enhancements to the background layer system.
    • DOE summary generation.
    • Preview panel redraw for project loading, etc.
    • Subshape offset calculation and application simplified.
    • Subshape group box now hidden (and internal geometry values reset) when no shape is chosen from the menu.
    • Lingering subshape (2/3) geometry when dropping down to configurations with fewer subshapes - fixed.
